🎵 Tidal DASH MPD 播放器

说明：
此播放器使用 DASH MPD Base64 Data URI + dash.js 播放 Tidal 音频。
MPD 播放列表是离线（Base64），但分段文件需要从 Tidal CDN 在线加载。
⚠️ 注意：
• 分段 URL 包含时效性 Token，需尽快播放
• 需要网络连接才能加载分段
• 某些浏览器可能有 CORS 限制

使用说明：

// 使用 dash.js const player = dashjs.MediaPlayer().create(); player.initialize(audioElement, mpdDataUri, true); player.on(dashjs.MediaPlayer.events.STREAM_INITIALIZED, () => { console.log('DASH 流初始化成功'); });
